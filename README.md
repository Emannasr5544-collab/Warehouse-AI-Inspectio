# Warehouse-AI-Inspection

AI-powered system for automated warehouse defect detection, leveraging YOLOv8 for real-time quality control.

## Overview
This project introduces a dual-model pipeline using **YOLOv8n** (speed-optimized) and **YOLOv8x** (accuracy-optimized) to detect defects such as torn surfaces and wrinkles in real-time within warehouse environments.

## Key Performance Indicators (KPIs)
* **Detection Accuracy:** 99.5% mAP@50
* **End-to-End Latency:** <67ms
* **Efficiency:** 80% faster than manual inspection
